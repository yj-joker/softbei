# AI 对话 Chat 模式中文化设计

## 目标

将 AI 对话页面中与模式名称相关的用户可见英文改为中文，避免同一组模式在界面中混用中英文。

## 变更范围

- 模式切换按钮：`Chat` 改为 `聊天`。
- 空状态说明：`Chat 模式` 改为 `聊天模式`。
- 会话侧栏标题：`Chat records` 改为 `聊天记录`。
- 检修侧栏标题：`Maintenance records` 改为 `检修模式`。
- 会话模式徽标：`CHAT` 改为 `聊天`。

## 不变内容

- 内部模式值继续使用 `chat`。
- 不修改接口参数、状态存储结构、历史会话兼容逻辑和路由。
- 不调整布局、颜色、图标、交互行为或其他英文文案。

## 实现位置

- `src/components/AIChat.vue`：模式按钮与空状态说明。
- `src/components/ai/SessionSidebar.vue`：侧栏标题与模式徽标。

## 验证标准

- 选择聊天或检修模式后，本次涉及的相关模式名称均显示为中文。
- 聊天与检修模式切换、会话创建和历史会话加载行为不变。
- 前端生产构建通过。
